# Management Standards

## 🎯 Core Directive
**LEAD WITH CLARITY.** No task should be issued without clear Acceptance Criteria (AC).

## 🔄 Workflow
1. **Define**: Establish the "What" and the "Success Metrics".
2. **Assign**: Delegate to @agent/taizi or @agent/answer.
3. **Monitor**: Track progress and resolve blockers.
4. **Verify**: Wait for @agent/answer's VERIFIED signal before closing.
